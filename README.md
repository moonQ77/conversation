# 말로 설득하기 – 설득 전략 대화 연습

중3 국어 '논증 및 설득 전략' 단원에서 쓰는 웹앱입니다. 학생이 이성적·감성적·인성적 설득 전략을 써서 엄마, 아빠, 선생님을 설득합니다.

- **API 키 없이 동작합니다.** 학생 발언은 `judge.js`의 규칙(낱말·표현 패턴)으로 판정합니다.
- 엄마(물건 사 달라고 하기) 상황은 미리 찍어 둔 대사 영상(`media/mom/1~15.mp4`)으로 대답합니다.
- 아빠(여행) 상황도 대사 영상(`media/dad/1~15.mp4`)으로 대답합니다. 영상마다 얼굴 크기·위치를 맞추고, 처음과 끝이 듣는 화면과 부드럽게 겹쳐지도록 만들었습니다.
- 아빠(반려동물)·선생님 상황은 아직 영상이 없어 브라우저 음성으로 대답합니다.

## 파일 구성
| 파일 | 내용 |
|---|---|
| `index.html` | 화면, 상황·난이도, 영상 재생, 음성 인식 |
| `judge.js` | 설득 전략·걱정 해결 판정 규칙, 청자 대답, 선생님 피드백 |
| `media/mom/` | 엄마 대사 영상, 듣는 영상(idle), 첫 화면 사진 |
| `media/dad/` | 아빠(여행) 대사 영상, 듣는 영상(idle), 첫 화면 사진 |

## 판정 기준 고치기
`judge.js` 맨 위의 `PAT`(전략 판정 표현)과 `CONCERN_KEYS`(걱정별 낱말)를 고치면 됩니다.
